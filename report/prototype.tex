\begin{minipage}[t]{0.57\textwidth}\vspace{0pt}
\texttt{wargame\_gui.py} supports interactive play, batch runs and turn-by-turn traces.
Users select policies, design and weather, then step through periods or run many games.
\texttt{Game.step} implements the sequence in Fig.~\ref{fig:net}; \texttt{MIPBRPolicy} solves the
allocation model; \texttt{MetaGame} computes the template-game analyses.

\texttt{experiments.py all} regenerates the reported experiments; see \texttt{prototype/README.md}.
Learning agents, Bayesian state estimates and multi-period policies remain to be developed.
